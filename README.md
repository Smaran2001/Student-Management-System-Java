# Student Management System (Java)

A lightweight, console-based Java application designed to perform CRUD (Create, Read, Update, Delete) operations for managing student records. Built using core Java collections to ensure efficient data lookup and manipulation.

## Features
- **Add New Students**: Insert student details including ID, Name, and Course.
- **View All Records**: Display the current list of registered students.
- **Search Student**: Fast key-based retrieval of student details using unique IDs.
- **Delete Record**: Safely remove student records from memory.

## Tech Stack
- **Language**: Java (JDK 26)
- **Data Structures**: `HashMap`, `ArrayList`
- **Environment**: Visual Studio Code / Terminal
